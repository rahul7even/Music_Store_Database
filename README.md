# Music_Store_Database

Music Store Database SQL Project

This project is a relational database designed for a music store. It manages data related to Customer,Employee, Artist,Playlist, PlaylistTrack, Album, Track, Invoice, InvoiceLine, MediaType and Genre. The goal is to demonstrate database design, SQL querying, and data analysis skills.

Objective:
-Design a normalized relational database
-Practice writing efficient SQL queries
-Analyze music store sales and customer behavior
-Demonstrate real-world database use cases

Database and Tools:
• PostgreSQL 
• PgAdmin4
